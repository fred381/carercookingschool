# The Carer's Cookery Book

An interactive online cookbook by Hamilton George Care, built with Next.js 14 and deployed on Vercel.

99 recipes across 14 chapters, designed for professional carers cooking for older people.

## Getting started

```bash
npm install
npm run dev
```

## Enabling analytics

This project includes `@vercel/analytics` and `@vercel/speed-insights`. The code is already wired up in the root layout, but **data will not be collected until you enable Analytics in the Vercel dashboard**:

1. Go to your project on [vercel.com](https://vercel.com)
2. Open the **Analytics** tab
3. Click **Enable**

The same applies to Speed Insights: enable it under the **Speed Insights** tab. Both are free on the Hobby plan.
